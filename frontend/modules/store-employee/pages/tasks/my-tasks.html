Task Guidelines & Operational SOP Policy

PLUS33 Coffee Store Operations Standard Operating Procedure
📌 1. Task Lifecycle & 5 Core Statuses
  • Pending (ASSIGNED): Newly assigned directive awaiting employee initiation.
  • Started: Active task timer started on bar by employee.
  • Ongoing (Awaiting Approval): Completion report & proof submitted; awaiting supervisor sign-off.
  • Completed: Work verified, approved, and closed by Shift Supervisor or Store Admin.
  • Blocked: Halted due to equipment failure, ingredient stockout, or physical obstacle.
  • Rejected: Employee rejected directive with a mandatory written operational justification.
⚡ 2. Employee Action Options
▶ Start Task Click when initiating task execution to start activity timer.
⏳ Extra Time Request a deadline extension from the assigner with a written operational reason.
❌ Reject Task Reject assigned directive with mandatory written reason if unassigned to shift duty or unqualified.
📋 Submit Report Attach photo proof/documents, work summary, & audit metrics (fridge temp / espresso shot timings).
🚫 Mark Blocked Use if an operational obstacle prevents completion. Enter obstacle notes for supervisor intervention.
🔍 3. Verification & Supervisor Approval / Revision
  • ✅ Approve & Mark Completed: Shift Supervisor or Store Admin reviews submitted proof and approves work as COMPLETED.
  • ❌ Request Revision: If work is incomplete, supervisor sends a written revision reason. The task returns to employee with a highlighted warning box to resubmit.
⏳ 4. Live Time Remaining Badge

Every task displays a dynamic live countdown badge e.g. ⏳ 20H 30M Left or ⚠️ Overdue by 15M based on the shift deadline.
